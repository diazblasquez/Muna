# 🍰 Müna - Pastelería 100% Artesanal

Bienvenido al repositorio de **Müna**, un e-commerce dedicado a la venta de pastelería artesanal. Este proyecto simula una tienda online completa con carrito de compras dinámico, catálogo de productos y proceso de checkout.

##  Descripción del Proyecto
Müna es una plataforma web responsiva diseñada para ofrecer una experiencia de compra fluida. Los usuarios pueden navegar por distintas categorías de dulces, visualizar detalles específicos de cada producto, gestionar su carrito en tiempo real y completar un formulario de envío para finalizar su pedido.

##  Secciones del Sitio

El proyecto cuenta con las siguientes secciones principales:

*   **Inicio (Home):** Vista principal con el catálogo general de productos y acceso rápido a las distintas familias de dulces.
*   **Categorías:** Secciones filtradas para facilitar la navegación:
    *   *Alfajores* (Marplatense, Keto, etc.)
    *   *Tortas* (Brownie, Lemon Pie, etc.)
    *   *Boxes* (Opciones para regalar como Box Aurora o Suspiro)
    *   *Otros* (Cookies y complementos)
*   **Detalle de Producto:** Página individual para cada producto donde el usuario puede seleccionar la cantidad o el tipo de presentación antes de agregar al carrito.
*   **Carrito de Compras:** Panel lateral desplegable (sidebar) que permite ver el subtotal, sumar/restar unidades o eliminar productos sin salir de la página actual.
*   **Checkout:** Formulario final donde el cliente ingresa sus datos de envío y facturación para confirmar el pedido.

## 🛠️ Tecnologías Utilizadas
*   HTML5 (Semántico)
*   CSS3 (Grid, Flexbox, Media Queries para un diseño Mobile First)
*   JavaScript (Manejo del DOM, LocalStorage para el carrito y consumo de API)
